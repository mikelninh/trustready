# TrustReady — Three Golden Cases

## 01 — Scan a real repository / AI product
Connect a representative product and return a reproducible readiness graph with evidence attached to every positive control and unknowns left explicit.

Pass only if a reviewer can inspect why each result exists.

## 02 — Gap → remediation
A product fails/partially meets several controls.

Pass only if TrustReady produces concrete, prioritised remediation actions that point to the missing evidence/control requirement rather than generic advice.

## 03 — Re-scan → prove closure
Apply remediations, re-scan and compare before/after.

Pass only if improved controls are backed by new/updated accepted evidence, stale findings remain visible and the score cannot improve merely because prose changed.
