# TrustReady — Verification

## Evidence today
- scanner/readiness model implemented;
- REST, MCP and WebMCP surfaces validated in CI;
- OpenAPI/free-vs-paid capability contract;
- Stripe checkout + signed entitlement path;
- buyer-facing evidence/remediation model documented;
- repository dogfooding direction.

## What is not proven yet
- independent auditor/procurement acceptance;
- broad cross-stack precision/recall of evidence discovery;
- real buyer conversion/value at scale;
- certification or legal compliance outcomes.

## Next proof
Dogfood TrustReady across multiple own products and one external pilot. For every control, store accepted evidence, false positives/negatives, remediation usefulness and re-scan closure. Publish an honest before/after buyer pack.

## Rule
TrustReady must never become an authority that asks the buyer to trust an opaque score.
