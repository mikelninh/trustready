# Security Delta Benchmark v1

Shipped via PR #30.

The benchmark reruns target-owned A/B security proofs across Digital Worker Factory, SafeVoice, GitLaw and PrüfPilot, records exact target revisions, verifies security-control file integrity during execution, preserves benign controls and fails closed on any post-boundary impact escape or holdout regression.

Truth boundary: this is causal engineering evidence for the named controlled scenarios. It is not a penetration test, certification, real-world breach-probability estimate, or proof that unknown vulnerabilities do not exist.
