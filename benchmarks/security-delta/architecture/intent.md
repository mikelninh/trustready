# Intent

## Problem
A green security test suite does not by itself show that a security control caused an improvement. We need counterfactual evidence: what happens to the same attack when the relevant deterministic boundary is absent versus present?

## User
Security-minded engineers, hiring teams, reviewers, and maintainers evaluating whether TrustReady-style agent boundaries produce measurable protection rather than security theater.

## Outcome
Produce reproducible, target-owned A/B evidence across four structurally different real repositories, including benign controls and frozen holdouts, then aggregate it without overstating the claim.

## Non-goal
Proving that any repository is universally or production secure.
