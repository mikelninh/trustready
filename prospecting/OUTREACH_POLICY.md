# Outreach policy

TrustReady outbound must be useful, specific and non-coercive.

Allowed framing:
- “We found a public-source security signal worth validating.”
- “We could not verify an independent boundary in the bounded source snapshot.”
- “If this path behaves the same way at runtime, the consequence could be …”
- “This is not a vulnerability claim; runtime validation is required.”

Forbidden framing:
- “Pay us or …” / “unless you pay …”
- threatening disclosure or reputational harm as leverage
- claiming exploitation when only source was read
- claiming a runtime control is absent merely because it was not publicly observable
- contacting a maintainer before human review of the cited evidence

Severe/credible vulnerabilities leave the sales funnel and enter responsible disclosure.
