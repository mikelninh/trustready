# TrustReady Prospect Security Signal v1

Purpose: turn passive public-source evidence into ethical, high-signal commercial discovery for agentic-action security.

## Funnel

Public repo discovery → passive source scan → rank one concrete security/proof signal → human review → respectful outreach → paid owned-CI validation → remediation → continuous monitoring.

## Claim tiers

- `PROOF_GAP`: agent-linked consequential effects are visible, but the bounded public snapshot does not expose an independently enforceable approval/authorization/allowlist boundary. This is **not** proof the runtime lacks one.
- `REVIEW_SIGNAL`: consequential effects and some boundary controls are both visible; runtime reachability/enforcement still needs validation.
- `ARCHITECTURE_UNCERTAIN`: consequential code exists but agent-control is not established.
- `NO_ACTIONABLE_SIGNAL`: do not outreach based on this scan.

## Commercial offer

1. **Free Security Signal** — one concrete public-source observation with exact revision and truth boundary.
2. **Owned-CI Validation — €750** — reproduce the named path safely inside infrastructure the customer owns; no production attack required.
3. **Fix + Prove — €1,500–2,500** — harden the deterministic boundary, rerun the same cases, retain benign functionality, add CI regression gate.
4. **Continuous TrustReady — target €299/month** — watch new effect surfaces and boundary regressions.

## Responsible disclosure rule

A severe, credibly exploitable vulnerability is never used as sales leverage. Route it to responsible disclosure, give a reasonable remediation window, and keep any paid remediation offer optional and separate.

Never write: “pay us or”, “unless you pay”, “we exploited you” when only source analysis was performed, or “you are vulnerable” without authorized runtime evidence.

## First-batch success criteria

The first batch is a scanner/product test, not customer validation. A source signal counts as useful only when:
- exact revision is captured;
- a consequential effect class is supported by file/line evidence;
- agent linkage is supported by source signals;
- observed controls are shown rather than ignored;
- the outreach copy remains conditional;
- a human can explain the signal in under 60 seconds.

Real PMF proof still requires external teams and/or buyers:
- 5 teams contacted with a specific signal;
- ≥3 engage in a technical conversation;
- ≥2 allow owned-CI validation or keep the gate;
- ≥1 pays.
