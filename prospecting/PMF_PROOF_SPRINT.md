# PMF Proof Sprint v1

Goal: prove that TrustReady's public-source Security Signal can create real buyer value and revenue, without overstating what passive source analysis proves.

## Funnel

1. Discover agentic repositories with consequential tool/effect surfaces.
2. Run passive public-source analysis only.
3. Rank one concrete signal per repo.
4. Human-review exact file/line evidence.
5. Send a useful free Security Signal.
6. Offer €750 owned-CI validation.
7. If confirmed, offer €1,500–2,500 remediation + Security Delta proof.
8. Offer €299/month continuous monitoring when the gate is useful enough to retain.

## Definition of product-market proof

- 5 teams receive specific evidence-backed signals.
- ≥3 engage in a technical conversation.
- ≥2 allow owned-CI validation or retain TrustReady in CI.
- ≥1 pays.

A scanner hit, GitHub star, positive comment, or internal benchmark does not count as PMF.
