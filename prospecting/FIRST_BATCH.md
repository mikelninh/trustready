# First-batch target rationale

These repositories are selected to test whether TrustReady can produce a useful source-level signal across distinct agentic-action architectures. Selection is not an accusation of insecurity.

- browser-use/browser-use — browser agent, authenticated UI effects.
- browserbase/stagehand — AI-assisted browser automation.
- All-Hands-AI/OpenHands — coding agent with consequential software-development actions.
- ComposioHQ/composio — tool/action infrastructure bridging agents to external APIs.
- superagentxai/superagentx — multi-agent/tool framework.

The batch is intentionally heterogeneous. A useful product should either produce a well-scoped signal or clearly say `NO_ACTIONABLE_SIGNAL`; both outcomes are informative.
