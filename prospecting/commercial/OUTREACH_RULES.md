# Outreach rules

1. Public-source analysis only before contact.
2. Never claim a vulnerability from static source analysis alone.
3. Never threaten consequences or use disclosure as sales leverage.
4. Serious security findings follow responsible-disclosure handling first.
5. Paid validation occurs only in systems the customer owns or explicitly authorizes.
6. Automated sending is disabled; every first contact requires human approval.
7. Source evidence, business relevance, and what remains unproven must all appear in the review record.
