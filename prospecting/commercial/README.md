# Commercial Prospect Pilot

The pilot ranks public repositories only after TrustReady's passive source scanner identifies relevant agent-action architecture.

## Discovery order

1. Find candidate-rich public source patterns such as model-selected email, file-write, shell, browser, messaging or payment actions.
2. Run Prospect Engine v2.2.
3. Score buyer/commercial relevance separately from security confidence.
4. Human-review only high-confidence candidates.
5. Draft outreach only after human approval.

A `PROOF_GAP` is not a confirmed vulnerability and never authorizes testing a third-party deployment. The system does not execute or attack third-party targets and does not send outreach automatically.

The second pilot batch intentionally includes low-commercial-fit and simulated/benchmark candidates as negative controls. A valid result may contain zero outreach candidates.
