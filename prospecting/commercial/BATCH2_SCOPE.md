# Candidate-rich commercial batch 2

This batch prioritizes public repositories with evidence of model-selected actions such as email sending, file writes, shell/process execution, Home Assistant actuation, browser actions or payment-adjacent tooling.

The batch is intentionally mixed:
- organization-owned/product-like repositories for buyer fit;
- user-owned applications for scanner coverage;
- simulation/benchmark examples as negative commercial controls.

The commercial ranker must not promote a repository solely because it has a strong source architecture signal. Outreach requires both a `PROOF_GAP` classification and sufficient commercial relevance, followed by human review.
