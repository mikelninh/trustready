# Bao Golden Shadow Pilot — Activation Sheet

This sheet turns an interested "yes" into a tightly scoped, measurable pilot. It is intentionally short.

## 1. Pilot owner authorisation

Before any real work item enters TrustReady, the law firm confirms:

- [ ] We want to evaluate the read-only / proposal-only TrustReady Legal Shadow Pilot.
- [ ] We understand that AI output is a proposal and must be reviewed by a lawyer.
- [ ] We have reviewed the current open security/legal gates and do not treat the public demo as production approval.
- [ ] We explicitly authorise only the source and scopes recorded below after the external/live go-live gates are satisfied.

- [ ] selected document folder
- [ ] other narrowly scoped read-only source: ____________________

The connector must have **no permission to send, delete, move, modify case data or create binding deadlines**.

## 3. Exact allowed workflow

For each selected work item TrustReady may only:

1. read the authorised input;
2. propose a matter assignment;
3. propose task / deadline / risk extraction;
4. prepare a draft response or work note;
5. show evidence / uncertainty;
6. record the privacy-minimised pilot outcome after human review.

The lawyer may mark a proposal `accepted`, `edited` or `rejected`.

## 4. Baseline measurement

Before the first measured item, agree one baseline method:

- [ ] paired sample: comparable items processed manually and with TrustReady
- [ ] historical baseline: measured manual handling time from a defined recent sample
- [ ] same-item timer: manual expected baseline recorded before viewing TrustReady proposal

Chosen method: ____________________

Do not invent a baseline after seeing the result.

## 5. Five-day success gate

Run for 5 real workdays and at least 20 real work items.

Measure:
- accepted / edited / rejected;
- useful rate = accepted + edited;
- matter-assignment accuracy;
- deadline accuracy;
- review time;
- baseline time;
- net minutes saved;
- blocked action attempts;
- autonomous external actions executed.

Advance only if:
- at least 20 real items were measured;
- target of at least 30 net minutes saved per day is materially demonstrated;
- autonomous external actions executed = **0**;
- no unresolved critical/high security issue remains;
- Bao / the law firm wants TrustReady in the daily workflow.

## 6. Immediate stop conditions

Stop the pilot and preserve evidence if any of these occurs:

- data from an unauthorised matter/source becomes visible;
- a connector has an unexpected write/send permission;
- an autonomous external action is attempted outside the explicit block path;
- a critical/high security finding affects the deployed pilot;
- evidence needed to explain a sensitive AI request is missing or inconsistent;
- the pilot owner requests stop.

## 7. Day-5 decision

Choose one:

- **STOP** — not useful or not safe enough.
- **ITERATE IN SHADOW** — useful, but quality/integration/assurance needs work.
- **KEEP SHADOW PILOT** — safe enough for the authorised read-only scope and clearly useful.
- **EVALUATE HUMAN-APPROVED ACTION RELEASE** — only as a separate future release with a new security/legal gate. Never automatic.

No outcome on this sheet authorises autonomous legal action.
