# TrustReady Sales OS — v1

Goal: turn TrustReady from portfolio proof into the first paid customer outcome without diluting technical truth.

## Commercial wedge

Sell **one 7-day Agent Security Proof**, not a broad platform subscription.

The customer buys:

**one consequential workflow → mapped authority/effects → attack replay → boundary hardening → before/after evidence → CI gate**

Founding price: **€1,500 + VAT**, first 3 teams.

## First 30-day experiment

Targets:

- 30 qualified accounts
- 8 personalized first-wave messages
- 2+ positive replies
- 5 discovery calls total
- 3 scoped proposals
- 1+ paid pilot

Do not increase outreach volume until the first 8 messages produce signal.

## Discovery call — 20 minutes

### 0–3 min — Product reality

Ask:

- What can the agent actually **do**, not just say?
- Which effects would be painful if triggered incorrectly?
- Where does authority come from today?

### 3–10 min — One workflow

Draw:

`input/context → model/agent → capability → policy/approval → executor/API/write`

Pick one consequential sink.

### 10–15 min — Testability

Confirm:

- owned/authorized sandbox or fixture;
- exact effect can be observed without real-world harm;
- benign control exists;
- safe weakened/baseline path can be created or historical pre-boundary evidence exists.

### 15–18 min — Pilot scope

State exactly:

- one workflow;
- 7 days;
- €1,500 + VAT;
- deliverables from `FOUNDING_PILOT.md`;
- no certification / pentest claim.

### 18–20 min — Close

If fit:

> “I’ll send a one-page scope with the exact action boundary, inputs, evidence and definition of done. If that looks right, we start when access is ready.”

If not fit, say so.

## Proposal rule

A proposal must fit on one page and name:

- target system;
- target workflow;
- consequential effect;
- authorization / access boundary;
- planned attack classes;
- benign control;
- evidence output;
- fixed price;
- start condition;
- explicit exclusions.

## Expansion path after a successful pilot

Only after paid pilots reveal repeated demand:

1. **Security Delta Assessment** — €3.5k–€10k scoped work
2. **Continuous TrustReady** — CI / evidence history / regression monitoring
3. **Team plan** — private repos + hosted evidence
4. **Enterprise** — SSO/RBAC/policy packs/support
5. **Verified evidence program** — only if the methodology and governance justify the label; never imply independent certification prematurely

## Anti-patterns

Do not:

- lead with EU AI Act consulting;
- sell “prompt injection solved”;
- call a controlled mutation a historical vulnerability;
- promise production security from a small benchmark;
- bury the one concrete effect under architecture slides;
- build SaaS features before a buyer pays for the underlying outcome.
