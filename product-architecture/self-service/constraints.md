# Constraints — TrustReady Self-Service v1

- Owned repositories / owned CI only for connected execution.
- No arbitrary shell command from config.
- Fixed recipe allowlist; `shell:false`; bounded timeout.
- Source preflight is not runtime proof.
- No production, third-party, payment, healthcare or destructive effects are automatically exercised by TrustReady v1.
- No penetration-test, certification, universal-security, or prompt-injection-solved claims.
- Missing/incomplete evidence fails closed.
